# 站点操作手册（运营岗位）

| 文档信息 | 内容 |
| --- | --- |
| 版本 | v4.1 |
| 生效日期 | 2026-08-01 |
| 适用岗位 | 站点站长、仓管员、派送员、站点运营专员 |
| 文档负责人 | 运营部标准组 |
| 适用范围 | 华驿物流所有直营与加盟站点（快递+仓配） |

## 1. 岗位职责

| 岗位 | 核心职责 |
| --- | --- |
| 站长 | 站点整体指标（时效、破损率、差异率）、异常件终审、红色滞留件处理 |
| 仓管员 | 到件验收、入库上架、异常登记、盘点 |
| 派送员 | 派前电联、二次派送、拒收/异常现场处置 |
| 运营专员 | 数据日报、滞留件跟踪、禁运台账维护 |

## 2. 到件与卸车

1. 车辆到达后 **30 分钟内**完成卸车，卸车全程轻搬轻放，大件使用叉车/托盘车；
2. 到件扫描在 **2 小时内 100% 完成**（当班内），扫描以运单条码为准，不得批量代扫；
3. 发现错分件（非本站派送区域）：**4 小时内**在系统登记并转出至正确站点，不得积压过夜；
4. 卸车时发现外包装明显破损的，当场拍照并在系统标记「异常件-破损」后再扫描入库。

## 3. 入库与上架验视

1. 大件（单边 ≥ 80cm 或重量 ≥ 20kg）：上架前必须拍照 3 张（正面、侧面、面单特写）；
2. 高值件（客户申报价值 ≥ 2000 元）及易碎品：开箱验视，双人复核，全程录像；录像保留 14 天；
3. 验视发现短少/破损：按第 5 节异常件流程处理，不得上架；
4. 上架库位与系统绑定，一物一位，不得混放。

## 4. 出库与派送

1. 派送前电联收件人，一天内两次电话无人接听则短信留言；
2. 首次派送失败：当日 18:00 前安排第二次上门；
3. 两次派送均失败：快件转站内滞留区，短信通知收件人与发件人；
4. 滞留第 3 天起每日短信/电话催派一次；
5. 自首次派送失败起 **第 7 天**仍无法交付的，转入退回流程（见第 6 节）。

## 5. 异常件处理

### 5.1 破损件

1. 立即停止派送/上架；
2. 拍照：外包装 + 内物损坏状态；
3. 系统登记「异常件-破损」，选择责任发现环节；
4. 移入异常区（独立库位，挂红色标识牌），不得与正常库存混放；
5. 当日通知发件网点与客服理赔岗。

### 5.2 拒收件

1. 派送员当场在 PDA 登记拒收并拍照（快件+拒收人/门牌）；
2. 当日回站后入「拒收」库位；
3. **24 小时内**安排退回班车，不得混入正常派送批次。

### 5.3 地址错误件

联系发件人确认正确地址当日内改派；无法联系的，按滞留件流程处理。

### 5.4 滞留件预警

| 状态 | 触发条件 | 处理要求 |
| --- | --- | --- |
| 黄色预警 | 到件后 24 小时未出库 | 仓管员当班处理 |
| 红色预警 | 到件后 48 小时未出库 | 站长必须当日亲自处理（派送/转退/上报问题件） |

## 6. 退件流程

1. 退回件单独打包并在系统登记「退回」，粘贴退回面单；
2. 每日 16:00 班车统一发出；
3. 退回件到发件网点后由发件方签收确认，站点跟踪至签收闭环。

## 7. 盘点与差异

1. **每日闭站前**：动碰盘点（当日有出入库动过的库位全数清点）；
2. **每周日**：全站全盘；
3. 差异率 = 差异件数 ÷ 在库总件数；
4. 差异率 > 0.5%：当日上报区域经理，48 小时内提交差异说明；
5. 差异率 > 1%：全站暂停发货，站长牵头复盘，区域经理到场。

## 8. 设备管理

| 设备 | 要求 |
| --- | --- |
| PDA | 每日开工前检查，电量 ≥ 60% 方可领用出班 |
| 电子秤 | 每周一用 5kg 标准砝码校准，误差 ±10g 内合格；超差停用报修 |
| 面单打印机 | 每日首张试打检查；热敏纸规格 100×180mm |
| 监控 | 运行正常每日巡检；录像保留 ≥ 30 天 |

## 9. 收寄验视与禁运品

1. 收寄 100% 开箱验视（信件除外），验视后在面单加盖验视章；
2. 禁运品清单：锂电池（独立寄件需危险品包装证明及双方资质）、易燃易爆品、单瓶容量 > 100ml 的液体、活体动植物、伪造证件及侵犯知识产权物品；
3. 发现疑似禁运品：当场拒收 + 登记《禁运品台账》+ 当日上报站点安全员；
4. 已误收入库的禁运品，单独隔离存放，严禁继续中转。

## 10. 安全与合规

1. 消防通道零堆物，每日班前检查；
2. 每月 5 日消防设施检查（灭火器压力、烟感、应急照明）并留档；
3. 站内严禁吸烟与明火作业；
4. 员工安全培训每季度一次，新员工上岗前必须完成安全培训。

## 11. 常见问题

- **问：客户坚持要寄 150ml 化妆水怎么办？** 答：单瓶超 100ml 属禁运品，应拒收并登记台账、上报安全员；可建议分装至 ≤100ml 或走合规化妆品专线（如有签约）。
- **问：周日全盘时刚好有在途派送件怎么算？** 答：派送中的快件计入「在库」基数，以当日 20:00 系统快照为准。
- **问：电子秤校准显示 5.01kg 合格吗？** 答：合格，误差 10g 在 ±10g 允许范围内。
